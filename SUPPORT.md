# Support

## Before Asking for Help

1. Read the README.
2. Check existing Issues.
3. Confirm that you are using a supported Node.js LTS release.
4. Reproduce the problem with the latest `main` branch when possible.

## Where to Ask

For bugs and reproducible technical problems:

https://github.com/Greenhawk5/HawkBucks-Web/issues

For feature ideas, use the Feature Request issue template.

For security vulnerabilities, do **not** use public Issues. Follow [SECURITY.md](SECURITY.md).

## Useful Information

Include:

- Operating system
- Node.js version
- npm version
- Browser and version for frontend issues
- Relevant component (`frontend` or `worker`)
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant console/build output

Never include passwords, Device Auth secrets, API tokens, private webhook URLs, or other credentials.
