# Security Policy

## Supported Versions

HawkBucks is currently maintained on the `main` branch.

| Version / Branch | Supported |
| --- | --- |
| `main` | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do **not** disclose security vulnerabilities through public GitHub Issues.

For sensitive reports, use GitHub's private vulnerability reporting / Security Advisories for this repository:

https://github.com/Greenhawk5/HawkBucks-Web/security

If private reporting is unavailable, contact the maintainer through the contact method listed in the repository profile.

## What to Report

Examples include:

- Exposed Epic Games credentials or Device Auth secrets
- Authentication or authorization bypasses
- API vulnerabilities
- CORS or origin-policy weaknesses
- Secret or token exposure
- Dependency vulnerabilities
- Cloudflare Worker configuration issues
- Unexpected access to private data

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a security issue.

Do not include live credentials, tokens, private URLs, or other sensitive values in reports, screenshots, logs, or pull requests.
